# Contador EC

Programa para Windows para contadores de Ecuador: descarga masiva de comprobantes del SRI de uno, varios o ilimitados RUC, control de clientes, formularios 104 y 103 y ATS en XML. Pago único de USD 40 por equipo y 7 días de prueba.

## Descargar el programa

Baje el instalador desde [Releases](../../releases/latest): `ContadorEC-Setup-1.0.0.exe`. Es para Windows 10 u 11 de 64 bits. Al instalarlo tiene 7 días de prueba con todas las funciones.

Para comprar la licencia escríbanos por WhatsApp. El pago es por transferencia bancaria.
